A template for an LPU Module instance that will be created on all instantiations of the parent device type.
Each LPU Module template instance is assigned a physical [LPU Module Type](lpumoduletype.md), a name, and a description (optional).
The name field supports alphanumeric ranges for bulk creation, for example, setting the name to `lpu_module_[0-3]` will create 4 LPU Module template instances with the digits in the name incremented from 0 to 3.

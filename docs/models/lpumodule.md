An LPU Module represents a physical inference-accelerator board, which is either in use and assigned to a device, or an available spare and assigned to a storage location.
Each LPU Module must be based on an [LPU Module Type](lpumoduletype.md), must have a name, and must be assigned to either a device or storage location.
Other information that can be tracked includes its serial number, asset tag, and description.
State data can also be set for the firmware version, the device driver name, and the driver version.
